# Zero Fashion

Premium apparel for men and women. Zero compromises on style, maximum focus on elegance.

## Features

- Premium product catalog
- Secure UPI payments
- Real-time order tracking
- Customer reviews and ratings
- Fully responsive design

## Getting Started

1. Install dependencies:
   ```sh
   npm i
   ```

2. Start the development server:
   ```sh
   npm run dev
   ```

3. Build for production:
   ```sh
   npm run build
   ```
